grab.

Short answers. With grab-server running, the Grab button saves a real file; otherwise it saves a demo file.

Live backend — checking…
grab-server speaks GET /api/grab?url=…&fmt=mp4-720 on 127.0.0.1:8000. Run uvicorn app:app --port 8000 in grab-server — audio formats also need ffmpeg (winget install ffmpeg).
Which links work? −

All standard YouTube shapes: youtube.com/watch?v=, youtu.be/, youtube.com/shorts/, and music.youtube.com. Playlists resolve to the first item in this demo.

What formats are available? +

Video: MP4 at 360p, 480p, 720p, 1080p (higher when source offers it). Audio-only: MP3 128/320, M4A/AAC, and WAV.

Does it add a watermark? +

Never. The file is the source rendition — no overlay or branding is added.

Is this legal to use? +

Only for content you have the right to save — your own uploads or where the creator permits it. Respect copyright and YouTube's Terms. Do not reupload without permission.
